# Default Field Reporter · Hotkey O

This feature stages a **REPORTER** lower third graphic for field journalists without requiring a cue in the rundown, utilizing stored operator defaults.

1. Navigate to **Default Settings → Field Reporter Defaults**.
2. Enter **Reporter Name**, **Title/Role** (default: `Reporter Lapangan`), and optional **Location**, then click **Save Field Reporter Defaults**.
3. In **Broadcast Control / Production**, press **O** or click the **O FIELD REPORTER** button.
4. Preview displays the configured reporter. Pressing **Space / →** airs or updates the graphic on Program; pressing **O** again reverts Preview to the selected story cue.
5. **Esc / C / ←** executes OUT. Master logo and ticker remain untouched.

Hotkey O is supported across all templates (CNN, Studio themes, Liputan7, BCC News). Staging a field reporter does not alter the active rundown or create phantom cues.
